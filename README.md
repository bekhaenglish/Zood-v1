# ZOOD — супер-приложение для Таджикистана 🇹🇯

Такси · Межгород · Доставка еды и товаров · Грузоперевозки — демо-версия экосистемы (5 ролей: клиент, водитель, партнёр, диспетчер, админ).

## 🚀 Запуск

Весь проект — **один файл `index.html`**. Ничего собирать не нужно.

**Локально:** просто открой `index.html` в браузере.

**GitHub Pages:** Settings → Pages → Branch: `main` → Save. Сайт появится на `https://<логин>.github.io/<репозиторий>/`

**Vercel:** vercel.com → Add New Project → выбери репозиторий → Deploy (настройки менять не нужно, это статический сайт).

## 📱 Загрузка с iPhone

Все файлы лежат **в корне без папок** — загружай через Safari: репозиторий → Add file → Upload files → выбери `index.html` и `README.md`.

## ✅ Что работает на живом сайте

- **Настоящая карта**: реальные тайлы CartoDB Voyager (стиль как в Яндекс Картах) во всех экранах — клиент, трекинг, доставка, водитель
- **Навигация**: маршрут по реальным дорогам (OSRM), белая подложка + зелёная линия, имитация пробок, жёлтый ETA-пузырь у точки Б
- **Синяя точка** геопозиции с пульсацией, кнопка 📍 центрирует карту
- **Геолокация**: кнопка 📍 определяет позицию (нужен HTTPS — Pages/Vercel дают его автоматически)
- **Реальные адреса**: поиск через OpenStreetMap Nominatim (введи 3+ буквы)
- **Сохранение данных**: профиль и заказы хранятся в браузере (localStorage)
- **Промокоды** в такси: NAVRUZ (−20%), SALOM (−15%), ZOOD10 (−10%) — цена пересчитывается сразу
- **Запланировать поездку**: «Через 30 мин / Сегодня 18:00 / Завтра 09:00» — бронь хранится и видна при возврате
- **Безопасность**: SOS-панель (звонок 112, служба ZOOD 24/7) и «Поделиться поездкой» (нативный share / буфер)
- **Раҳмат-чаевые** водителю после поездки + конфетти 🎉
- **Выбор города** (7 городов Таджикистана) — карта открывается в вашем городе
- **Переключатель РУ/ТҶ** в шапке — главный экран на таджикском
- Все 5 приложений, автоприём заказов, живой цикл статусов, оплата (АЛИФ, Эсхата, Душанбе Сити, Корти Милли)

## 🔧 Исходник

`zudgo.source.jsx` — исходный React-код (карта Leaflet синхронизирована; фичи v11 — промокоды, SOS, город, ТҶ — пока только в index.html, он основной). `index.html` собран из него (tsc → inline JS + React/Recharts с CDN).
